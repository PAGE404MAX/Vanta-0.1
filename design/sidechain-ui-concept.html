LINK A SIDECHAIN IN FL STUDIO

For example, duck your bass each time the kick plays:

  1. Put VANTA Sidechain on the bass mixer track.
  2. Select the kick mixer track. Right-click the send arrow on the bass track and choose “Sidechain to this track.”
  3. In the plugin wrapper’s Processing settings, assign and activate the external sidechain input if FL Studio requires it.
  4. Select SIDECHAIN here, play the track and adjust the threshold if needed.
This is a design preview. Routing and audio are not active here; actual FL Studio behavior must be tested after the VST is built.
